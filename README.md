# KZKT Desktop

Automated Manga & Webtoon Translator for PC (Windows, Linux, macOS).

## Downloads
Visit the [Releases](https://github.com/kouzen-neo/KZKT-Desktop/releases) page to download native installers for your operating system:
- **Windows**: `.exe` / `.msi`
- **Linux**: `.deb` / `.rpm`
- **macOS**: `.dmg`

## Features
- Offline YOLOv8 speech bubble detection
- Offline Tesseract OCR text extraction
- Smart OpenCV inpainting & interactive retouching brush
- Multi-LLM provider support (Google Gemini, OpenAI, Claude, Ollama)
- Full Studio workspace with real-time editing
